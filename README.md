# Чистотека

Профессиональный сайт химчистки Никиты Семьянова. Бело-синяя палитра, реальные фотографии, отдельные страницы услуг, разборы работ, обучение и подготовка обращения в Telegram.

## Локальный запуск

Требуется Node.js 22.12+ или 24.

```sh
npm ci
npm run dev
```

Открыть `http://localhost:5173`.

## Сборка и проверка

```sh
npm run build
npm run check
npm run preview
```

В `dist` собираются 20 страниц с готовым HTML, отдельными заголовками и метаописаниями, а также страница 404. Внутренняя навигация работает через History API. Прямые ссылки доступны благодаря отдельным `index.html` в папках маршрутов.

`npm run check` проверяет заголовки H1, уникальность ID, внутренние ссылки, изображения и ресурсы в head.

## Что работает

- Шесть подробных страниц услуг.
- Четыре интерактивные вкладки материалов с клавиатурной навигацией.
- Три разбора с исходными публичными публикациями.
- Сравнение фото до/после ползунком и рядом.
- Сбор заказа из нескольких изделий, выбор количества, материала и задачи.
- Предварительный ориентир по базовым ценам, переход к ручной оценке для сложных материалов.
- До пяти локальных фото с превью и удалением.
- Сохранение текстового черновика в текущей сессии браузера.
- Подготовка текста, копирование и переход в Telegram Никиты.
- Обучение: аудитории, программа, форматы, тарифы и обращение.
- Три полезных материала, FAQ и страница конфиденциальности.
- Мобильная навигация, нижняя панель обращения, доступность диалога и reduced motion.

## Обращения и фотографии

Сайт статический. Собственного сервера заявок, CRM и приёма платежей нет. Форма готовит сообщение для Telegram: отправку выполняет посетитель. Выбранные фотографии остаются на устройстве, не загружаются на сервер и прикрепляются к сообщению отдельно в Telegram. Это ясно указано в форме и на странице конфиденциальности.

## Обновление содержания

- `src/data.js` — контакты, услуги, кейсы, материалы, статьи и направления обучения.
- `src/main.js` — страницы, компоненты и взаимодействия.
- `src/style.css` — дизайн, адаптация и анимации.
- `public/assets` — локальные изображения и шрифты.
- `asset-sources.json` — исходные URL изображений из существующего сайта и канала.

Цены услуг и обучения взяты с публичных страниц проекта. Перед коммерческим запуском владельцу следует актуализировать прайс, тарифы, географию, участие специалистов и договорные условия. Отзывы клиентов и финансовые результаты не выдумывались.

## GitHub Pages

Подготовлен `.github/workflows/pages.yml`. Публикация на других хостингах не настроена.

Репозиторий: [savokingi/chistoteka](https://github.com/savokingi/chistoteka).

Адрес сайта: [savokingi.github.io/chistoteka](https://savokingi.github.io/chistoteka/).

Для обновления сайта выполните push изменений в ветку `main`. Workflow собирает страницы, проверяет ссылки и изображения, затем публикует `dist` через GitHub Pages. Источник публикации в Settings → Pages — **GitHub Actions**.

Путь репозитория автоматически учитывается в Vite и предварительной генерации. Переменная `SITE_URL` используется для canonical, Open Graph, структурированных данных, sitemap и robots. Для собственного домена нужно обновить `SITE_URL` и base в конфигурации.

Сборка для подпапки проверялась с `GITHUB_REPOSITORY=preview/chistoteka`, `GITHUB_ACTIONS=true` и `TEST_BASE=/chistoteka/`.
